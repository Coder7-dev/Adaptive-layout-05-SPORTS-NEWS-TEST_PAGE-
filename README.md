Название: Лендинг Sporthub

Стек: HTML, CSS (SCSS), JS (jQuery)

Задачи:
1. Спроектировал модульную архитектуру стилей (компонентный подход), разбив интерфейс на независимые SCSS-модули, что повысило читаемость кода и упростило командную разработку.
2. Реализовал централизованное управление дизайном через SASS-переменные для глобального контроля цветовой палитры и шрифтовых констант сайта.
3. Спроектировал гибкий, масштабируемый интерфейс с использованием относительных единиц измерения em для всех размеров, внутренних отступов и адаптивных брейкпоинтов.

Фичи: 
1. Оптимизировал производительность и скорость загрузки страницы на мобильных устройствах за счет динамической подмены фоновых изображений под разные брейкпоинты.
2. Применил компонентно-ориентированный подход в SCSS, инкапсулировав адаптивные медиа-запросы непосредственно внутрь родительских стилей для повышения поддерживаемости кодовой базы.
3. Спроектировал асимметричную двухрядную сетку на CSS Grid с жестким контролем высоты строк в em, предотвращающую наложение или схлопывание блоков при динамической загрузке текстов, с переводом к гибкому одномерному потоку на мобильных устройствах.
4. Разработал кастомный цикличный слайдер с плавной кросс-фейд анимацией и реализовал логику переключения слайдов на базе классов состояний (.current).
